# 글로벌 사업화: 보류 원칙과 시작 조건

결정(2026-10-24): 글로벌 기능은 지금 개발에 반영하지 않습니다. 한국에서 기능을 인정받은 뒤 90일 안에 구체적인 계획을 세웁니다.

## 시작 조건 (모두 충족 시 90일 계획 수립 착수)

| 조건 | 기준 |
|---|---|
| 목표-과제 일치 | 국내 실제 사용자 목표 50건에서 불일치 신고 5% 이하 |
| 유료 검증 | 지인 외 고객의 단건 결제 10건 이상 (유료 버전 출시 후) |
| 반복 이용 | 참여자 20명 중 8명 이상이 2주 연속 체크인 |
| 지식재산 | 국내 특허 출원(공지예외 마감 2027-10-24 이전)과 상표 검색 완료 |

## 그때 세울 90일 계획의 뼈대 (참고용, 지금은 개발하지 않음)

| 기간 | 주제 | 미리 적어 둔 과제 |
|---|---|---|
| 1~30일 | 계산 설계 | 출생 도시·당시 시간대·서머타임·날짜 경계 처리, 계산 엔진·규칙 버전 기록, 경계 사례 기준 데이터 확장 |
| 31~60일 | 영어 핵심 화면 | ‘Korean Saju’ 입문 설명, 결과 카드, 주간 계획. 한국어·영어 해설 의미 일치 검수(원어민 감수) |
| 61~90일 | 소규모 유입 실험 | 채널별 완료율·구매율·획득비용 비교, 영어 사용자 10명 오류 수정 |

## 지금 지켜 둘 것

- 새 기능은 해외 확장을 막지 않게 만듭니다(예: 시간 처리를 한곳에 모으기, 문안을 데이터 파일로 분리).
- 해외 특허 가능성은 국내 출원 상담 때 함께 확인합니다(일부 국가는 이미 공개된 발명을 인정하지 않음).
