| # | 발명 아이디어 | 핵심 처리 단계 | 차별점 가설 |
|---|---|---|---|
| A | 전통 역법 계산과 사용자 목표 해석을 결합한 주간 행동계획 생성 방법 | ① 생년월일시를 절입 시각·지방 태양시로 이원 보정해 명식 산출 ② 자유 목표 문장에서 분류·기한·수치·시험명 추출 ③ 사용자가 고른 고민 분류와 비교해 불일치를 확인 ④ 주차별 단계 템플릿과 가용 시간으로 과제·시간 배분, 합계를 가용 시간 안으로 조정 ⑤ 체크인(완료·난이도)으로 다음 주 분량·단계를 갱신 | 운세 해설과 근거가 분리된 계획 생성(사주는 참고, 계획 근거는 사용자 입력) |

## 3. 상표

- ‘운명 연구소’는 흔한 낱말의 조합이라 식별력이 약하다는 거절 가능성이 있습니다. 고유한 브랜드명(예: 영문 조어)을 함께 만들어 출원하는 편이 안전합니다.
- 지정 상품·서비스업 후보: 제45류(운세·점술 제공업), 제9류(내려받기 가능한 앱 소프트웨어), 제42류(온라인 비내려받기 소프트웨어 제공, SaaS), 제41류(교육·콘텐츠 제공).
- KIPRIS 상표 검색으로 같은·비슷한 상표부터 확인하세요.

## 4. 저작권

- 소스 코드, 해설 문안(일간별 풀이, 토정 해설, 타로 해설, 행동계획 문장), 일간 장면 그림은 만든 순간 저작권이 생깁니다.
- 한국저작권위원회 저작권 등록(프로그램 저작물, 어문 저작물)을 하면 창작 시점과 저작자를 추정받아 분쟁 때 유리합니다.
- 저장소에 `LICENSE`(All rights reserved)와 사이트 하단 저작권 표시를 넣었습니다.

## 5. 공개 저장소와 유료화 구조

현재 저장소가 공개라 모든 규칙과 문안을 누구나 볼 수 있습니다. 유료 버전을 만들 때는 다음 구조를 권합니다.

| 구분 | 위치 |
|---|---|
| 무료 체험(기본 계산, 요약 해설) | 지금처럼 공개 정적 페이지 |
| 유료 기능(목표 해석 규칙 고도화, 상세 해설 DB, AI 상담 지침) | **비공개 저장소 + 서버 측 실행** (영업비밀로 보호) |
| 특허 출원 대상 처리 흐름 | 출원 후 공개 |

깃허브 Pages를 비공개 저장소에서 쓰려면 유료 요금제가 필요합니다. 유료 단계에서는 Cloudflare Pages 같은 다른 호스팅도 검토하세요.
