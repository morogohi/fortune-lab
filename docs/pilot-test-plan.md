# 운명 연구소 국내 시범 테스트 계획 (4주)

목표: “운세가 맞는가”가 아니라 **“읽고 나서 생각이 정리되고 할 일이 생기는가”**를 확인합니다.
범위: 국내, 무료 공개판(https://morogohi.github.io/fortune-lab/). AI 상담과 결제는 이번 범위에서 제외합니다.

## 1. 통과 기준

| 항목 | 기준 | 확인 방법 |
|---|---|---|
| 목표-과제 일치 | 준비한 20개 목표 사례 모두 일치 | `npm test` (자동 검증 92항목, 2026-10-24 전부 통과) |
| 첫 사용 완료 | 참여자 15명 중 12명 이상이 도움 없이 결과와 이번 주 계획을 확인 | 관찰 기록 |
| 과제 실행 | 참여자의 절반 이상이 과제 1개 이상 실행 | 1주 뒤 체크인 또는 피드백 3번 문항 |
| 재사용 | 참여자 15명 중 6명 이상이 2주차 체크인까지 사용 | 계획 파일 내보내기 여부 확인 또는 피드백 |
| 지불 의향 | ‘4,900원 이상이면 산다’ 응답 비율 확인(기준은 1주차 결과로 정함) | 피드백 6번 문항 |

## 2. 참여자 (15명)

| 그룹 | 인원 | 이유 |
|---|---|---|
| 자격증·시험 준비 중인 성인 | 5 | 목표-과제 일치가 가장 잘 드러나는 집단 |
| 이직·진로 고민 중인 직장인 | 5 | 경력 연계 직무, 주간 계획 검증 |
| 운세 콘텐츠를 즐기는 일반 사용자 | 5 | 첫 화면 이해도와 재미 검증 |

가능하면 지인 외 참여자를 절반 이상 포함합니다.

## 3. 진행 순서

| 주차 | 할 일 |
|---|---|
| 0주 | 참여자에게 안내문 전달(아래 4번), 사이트 주소와 피드백 방법 공유 |
| 1주 | 각자 입력 → 결과 확인 → ‘나의 목표’ 작성 → 이번 주 과제 확인 → 계획 파일 내보내기. 운영자는 3~5명을 화면 공유로 관찰 |
| 2주 | 계획 파일 불러오기 → 체크인 → 2주차 계획 확인 → ‘시범 테스트 의견 보내기’ 작성 |
| 3주 | 피드백 정리, 모순·이해 안 된 문장 수정, 목표 분류 규칙 보강 |
| 4주 | 수정판으로 5명 재확인, 유료 상품(목표별 4주 계획 리포트) 구성 확정 |

## 4. 참여자 안내문 (복사해서 보내기)

> 운명 연구소 시범 테스트에 참여해 주셔서 감사합니다.
> 사이트: https://morogohi.github.io/fortune-lab/
> 1) 생년월일과 ‘나의 목표’(3개월 뒤 원하는 변화)를 적고 결과를 봐 주세요. 입력한 정보는 브라우저 안에서만 계산되고 저장·전송되지 않습니다.
> 2) ‘이번 주 계획’ 탭의 과제 3개 중 하나라도 해 보고, 일주일 뒤 체크인해 주세요. 이어서 쓰려면 ‘계획 파일로 내보내기’로 저장해 두세요.
> 3) 맨 아래 ‘시범 테스트 의견 보내기’를 작성하고 ‘의견 복사’ 후 이 메시지로 보내 주세요.
> 재미와 자기성찰을 위한 서비스이며, 중요한 결정의 근거로 쓰지 마세요.

## 6. 개인정보 원칙 (시범 기간)

- 사이트는 입력값·피드백·계획을 수집하지 않습니다. 피드백은 참여자가 직접 복사해 보낸 글만 받습니다.
- 받은 피드백에는 생년월일·이름을 적지 않도록 안내합니다. 설문 폼을 쓰려면 `js/config.js`의 `feedbackUrl`에 주소를 넣으세요(폼에서도 생년월일은 묻지 않기).
- 관찰 기록은 참여자 번호로만 남깁니다.
