# life-test 검증 스크립트 (Playwright · Python)

저장소 루트에서 `python3 -m http.server 8765` 로 띄운 뒤 이 폴더에서 실행합니다. (Chrome: /usr/bin/google-chrome)

| 파일 | 확인 내용 |
|---|---|
| t_counsel.py | 대화·선택 상담 같은 입력 → 같은 기본 점수·분야 · A/B 순서 바꿈 · 다시 실행 · 같은 뜻의 표현 · 주의 달과 실행 달 분리 · 기준 연도 표시 |
| t_ctx.py | 예전 기록 보존 · 확인 질문 무과금 · 3 카르마 차감 · 후속 질문 조건 갱신 · 주제 전환 · 연속 클릭 · 실패 환불 · 프로필 분리 · 지난 상담 당시 기준 |
| t_pdf.py / chk_pdf.py | 궁합 부록 없는/있는 PDF 생성 → 글꼴 포함·한국어 검색·글줄 겹침·꼬리말 침범·반복 문장 |
| t_pdf2.py | 생성 실패 → 재시도(추가 차감 없음) · 무료 재열람 · 구매 권한 키 · 미리보기 간격 · 표 머리글 반복 |
| t_regress.py | 주요 화면 · 미래 생년월일 차단 · 프로필 취소/검증 실패 유지 · 한국 날짜 · 다른 시간대 · 광고 +5·대기시간 · 상담 가격 설정 |
| t_nologin.py | 로그인 요소·문구 없음 · 기기 저장 안내 · 4주 계획 선택지·실행 달 · 관련 달/권장 실행 달 문장 · 성향 검사 프로필 연결(예전 기록 보존) · 무료 타로/오늘의 운세 독립 클릭(마우스·키보드) · 여러 탭 잔액 · 저장 실패 무차감 · 중복 클릭 · 새로고침 유지 · 게임 이어하기 · 인증 요청 없음 |
| t_consist.py | 여러 프로필 × 동의어 × A/B 순서에서 기본 점수·현실 조언 선택 일치 |
| t_feedback.py | 리포트를 보다 화면을 껐다 켜도 위치 유지 · 사주 MBTI 안내 · 실제 MBTI 고르면 상담·리포트·신년 전략이 실제 MBTI 기준 |
| t_tarot.py | 오늘의 타로: 카드를 골라도 보던 위치 유지 · 결과 카드가 화면 안에 보임 · 미션 보상 |
